# BorrowHub

BorrowHub adalah aplikasi web multi-tenant untuk pengelolaan peminjaman peralatan organisasi.

## Repository

- `apps/web`: aplikasi React.
- `services/identity`: identitas, organisasi, membership, dan session.
- `services/inventory`: item, unit, kategori, dan maintenance.
- `services/lending`: permintaan, reservasi, checkout, dan return.
- `workers/notification`: consumer event dan pengiriman notifikasi.
- `contracts`: contract HTTP dan domain event.
- `deployments`: konfigurasi deployment.
- `observability`: metrics, dashboard, log, dan alert.
- `docs`: dokumentasi arsitektur dan operasi.
